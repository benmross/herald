# projects/

Where code Herald writes with you lives.

Each project is its own git repository, ignored by Herald's. A session started
from your phone, the Claude app or a terminal can `cd` in here and work with the
full ledger still one directory up — which is the point: the thing writing your
code knows your deadlines, your commitments, and what you are actually trying to
do.

Nothing here is published unless you ask. When Herald starts a project it
creates the repository **private**, and the constitution forbids it from making
anything public or pushing to a repository you did not ask it to create.
